# 给小彤的周日计划

这是一个纯 HTML/CSS/JavaScript 的情侣约会选择网页。

## 使用
直接双击 `index.html` 即可在浏览器打开（仅浏览功能）。**自动提交反馈需要把网页部署到线上**（见下方「发布」），用浏览器直接打开本地文件时自动提交会失败，此时可用「导出我的反馈」兜底。

## 发布
推荐上传到 GitHub Pages（免费）。把本目录下所有文件（index.html / script.js / style.css / README.md）上传到仓库根目录，在仓库 Settings → Pages 开启 Deploy from a branch（main / root），等 1-3 分钟后访问 `https://用户名.github.io/仓库名/`。自动提交功能必须在线上网址使用。

## 新功能
- 每个方案新增「LX TIPS」：来自 lx 的贴心小提示。
- 每个方案新增「小彤有话说」：小彤可以随时写下自己的想法和意见，选填即可；内容保存在浏览器 localStorage 中。
- 「提交反馈 · 自动发给 lx」：小彤填完评分和留言后点击，页面生成「反馈报告」（含评分汇总、留言、最高分分析与建议），通过 Web3Forms 自动发送到 lx 的邮箱，无需小彤再手动操作。
- 「导出我的反馈」：兜底功能。自动提交失败或断网时，小彤点击可下载一份 `小彤_周日计划反馈.txt`，把文件发给 lx 即可。

## Web3Forms 配置
自动提交依赖 Web3Forms 服务（免费，每月 50 次提交，个人使用足够）：
1. 在 web3forms.com 用**收件邮箱**注册（提交结果会发到这个邮箱）。
2. 创建 Form，Website URL 填网页线上网址。
3. 把拿到的 Access Key 填入 `script.js` 顶部：
   `const WEB3FORMS_ACCESS_KEY = "你的密钥";`
（当前代码已填入有效密钥；若更换账号/邮箱，替换这一处即可。）

## 说明
- 评分与留言保存在浏览器 localStorage 中，只会保存在当前设备/浏览器。
- 自动提交失败或对方不方便提交时，用「导出我的反馈」下载 txt 文件转发即可。
- 电影方案已填入两部候选片（《我想留在你身边》《坠落2：死点》），均确认在北京热映中；下映后可以把片名替换为当时在映的影片。
- 手工方案列举了几家北京 DIY 店铺（玩个手作、瓷语、漫喜画瓷、十六手工皮具），出发前建议先在平台确认营业与预约情况；也可以根据实际情况替换为最终选定的工作室。
