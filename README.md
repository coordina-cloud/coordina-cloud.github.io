# 给小彤的周日计划

这是一个纯 HTML/CSS/JavaScript 的情侣约会选择网页。

## 使用
直接双击 `index.html` 即可在浏览器打开。

## 发布
可以上传到 GitHub Pages、Netlify、Vercel 等静态网站托管服务。

## 新功能
- 每个方案新增「LX TIPS」：来自 lx 的贴心小提示。
- 每个方案新增「小彤有话说」：小彤可以随时写下自己的想法和意见，选填即可；内容保存在浏览器 localStorage 中。
- 「提交答案 · 发送到邮箱」：小彤填完评分和留言后点击，会自动生成一份「反馈报告」（含评分汇总、留言、最高分分析与建议），并调起她设备上的邮件应用，收件人、主题和正文都已填好，她点发送即可发到你的邮箱。
- 「复制报告」：如果小彤的设备不方便用邮件，可一键复制报告全文，粘贴到微信/短信发给你。

- 评分与留言保存在浏览器 localStorage 中，只会保存在当前设备/浏览器。
- 邮件发送依赖小彤设备上已登录的邮件应用（如系统邮件 App、Gmail、QQ 邮箱等）；如果她那边点提交后没有弹出邮件窗口，用「复制报告」把内容粘贴到微信发给你即可。
